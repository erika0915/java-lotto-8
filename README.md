# 🚀 로또 (Lotto) 미션

## ✅ 기능 목록 
1. 로또 구입
- 로또 구입 금액을 입력받는다. 
  - (검증) 구입 금액이 1,000원 단위인지 검증한다. (1,000원으로 나누어 떨어지는지)
  - (검증) 구입 금액이 숫자인지, 양의 정수인지 검증한다. 
  - (예외) 잘못된 구입 금액 입력 시, [ERROR] 메시지를 출력하고 재입력 받는다. 

2. 로또 발행
- 구입 금액에 맞춰 로또를 발행한다. (1000원 당 1장)
  - `Randoms.pickUniqueNumbersInRange(1, 45, 6)` 를 이용해 1-45 사이의 중복 없는 6개 숫자를 생성한다. 
  - 생성된 번호로 Lotto 객체를 생성한다. 
  - Lotto 클래스는 validate 메서드 외에 필요한 검증 (범위, 중복) 및 기능을 가진다. 
    - 로또 번호 개수 6개 검증 (제공됨)
    - 로또 번호 범위 (1-45) 검증 
    - 로또 번호 중복 없음 검증 
  - 발행된 모든 로또를 저장 
  - 발행한 로또 수량을 출력한다. (예: "8개를 구매했습니다.")
  - 발행한 로또 번호(오름차순 정렬)를 모두 출력한다. 

3. 당첨 번호 및 보너스 번호 입력 
- 당첨 번호 6개를 쉼표 (`,`) 기준으로 입력받는다. 
  - (검증) 당첨 번호가 1-45 범위 내인지 검증한다. 
  - (검증) 당첨 번호 개수가 6개인지 검증한다. 
  - (검증) 당첨 번호에 중복이 없는지 검증한다. 
  - (예외) 잘못된 당첨 번호 입력 시, [ERROR] 메시지를 출력하고 재입력 받는다.
- 보너스 번호 1개를 입력 받는다. 
  - (검증) 보너스 번호가 1-45 범위 내인지 검증한다. 
  - (검증) 보너스 번호가 당첨 번호 6개와 중복되지 않는지 검증한다. 
  - (예외) 잘못된 보너스 번호 입력 시, [ERROR] 메시지를 출력하고 재입력 받는다. 

4. 당첨 통계 및 수익률 계산
- Enum을 활용하여 당첨 기준 (등수, 일치 개수, 보너스 유무, 당첨금)을 관리한다. 
- 발행된 각 로또와 당첨 번호, 보너스 번호를 비교한다. 
  - Lotto 클래스에 당첨 번호와 일치하는 개수를 반환하는 기능 
  - Lotto 클래스에 보너스 번호 포함 여부를 반환하는 기능 
- 당첨 등수 (1-5등, 꽝)을 판별한다. 
- 등수 별 당첨된 로또 개수를 집계한다. 
- 총 당첨금을 계산한다. 
- 총 구입 금액 대비 총 수익률을 계산한다.
  - 수익률은 소수점 둘째 자리에서 반올림하여 첫째 자리까지 표시한다. 

5. 결과 출력 
- 당첨 통계 헤더를 출력한다. ("당첨 통계 \n---")
- 5등부터 1등 순서대로 당첨 내역을 출력 형식에 맞게 출력한다. (예: "3개 일치 (5,000원) - 1개")
- 총 수익률은 형식에 맞게 출력한다. (예: "총 수익률은 62.5%입니다.")

6. 테스트 코드 작성
- Lotto 클래스에 대한 단위 테스트를 작성한다. 
- 구입 금액, 당첨 번호, 보너스 번호 검증 로직에 대한 단위 테스트를 작성한다. 
- 당첨 등수 판별 및 수익률 계산(비즈니스 로직)에 대한 단위 테스트를 작성한다. 
- UI (입출력) 관련 로직은 테스트에서 제외한다.
